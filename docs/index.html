O que faz

Funcionalidades

Tudo embarcado no ESP32 — sem cloud, sem backend, sem dependências externas.

⏱️

Agendamento por Intervalo

Defina quantas horas e minutos entre cada alimentação diretamente pelo dashboard. Configuração em tempo real via API REST.

🕐

Horário Fixo via NTP

Configure um horário diário (ex: 08:00) e o ESP32 sincroniza com pool.ntp.org para disparar exatamente na hora certa.

📱

Dashboard Web Embarcado

Interface dark mode responsiva servida pelo próprio ESP32. Sem recarregamento — atualiza via fetch() a cada 2 segundos.

🌡️

Monitoramento Ambiental

Temperatura e umidade em tempo real via DHT22. Exibidos no dashboard e no LCD I2C 16×2 do hardware.

📊

Nível de Ração

Barra de progresso animada com alertas de reabastecimento. A ração zera ao abrir a porta e reseta ao clicar "Reabastecer".

🔔

Alertas Não Bloqueantes

Buzzer e LEDs controlados por máquina de estados — sem nenhum delay(). O loop principal nunca trava.

Interface

API REST

O ESP32 expõe 6 endpoints. Nenhuma autenticação necessária na rede local.

Método Rota Descrição
GET / Serve o dashboard HTML completo
GET /api/status Retorna o estado completo em JSON (polling a cada 2s)
POST /api/feed Dispara alimentação manual imediata
POST /api/close Fecha a porta manualmente
POST /api/refill Reabastece a ração — reseta foodLevel para 100%
POST /api/schedule?mode=interval&minutes=30 Define intervalo de 30 min entre alimentações
POST /api/schedule?mode=time&hour=8&min=0 Alimenta todo dia às 08:00 (horário Brasília via NTP)

Guia

Como Executar

Simule o projeto no Wokwi em menos de 5 minutos.

1

Instalar pré-requisitos

VS Code + extensão Wokwi for VS Code + Arduino IDE 2.x com suporte ESP32 (Boards Manager).

2

Instalar bibliotecas

No Arduino IDE → Library Manager: ESP32Servo, LiquidCrystal I2C, DHT sensor library for ESPx.

3

Compilar o firmware

Abra pet-smart-feeder/ no Arduino IDE, selecione ESP32 Dev Module e pressione Ctrl+R. Os binários são gerados em build/.

4

Iniciar a simulação

Abra o diagram.json no VS Code com a extensão Wokwi. Pressione F1 → Wokwi: Start Simulator.

5

Acessar o dashboard

Abra http://localhost:8280 no navegador. O dashboard atualiza automaticamente a cada 2 segundos.

ESP32Servo Controle do servo SG90 via PWM — versão >= 0.13.0
LiquidCrystal I2C Display LCD 16×2 via barramento I2C — versão >= 1.1.2
DHT sensor for ESPx Leitura não bloqueante do DHT22 — versão >= 1.19.0
